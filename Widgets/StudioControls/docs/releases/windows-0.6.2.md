# Studio Controls 0.6.2 for Windows

Open **Workflow editor**, the second navigation item after **OBS**, to arrange scenes, set their durations and rehearse the sequence. The camera, screen and project tabs adapt their controls to the available window width. Use the information button beside a field to see what it changes.

The per-user MSI supports Windows 11 x64 and requires **Microsoft .NET Runtime 10.0 for Windows x64**. If a compatible runtime is already installed, you can use the MSI immediately. Otherwise install the runtime separately, then open the MSI. [Download .NET 10 from Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)
