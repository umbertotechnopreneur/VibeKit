# Prepare a workspace

Open a local Markdown file or folder in the Windows application.

## Installation

Install the Release x64 MSIX with .NET Runtime 10.0 and WebView2 Runtime available.
Open **sample workspace** for these examples, or **Open folder** / **Open file**
for your own documents. Folder refresh rereads local metadata and links.

### A tiny example

~~~text
notes/
  README.md
  guide/
    setup.md
  assets/
    workspace.svg
~~~

The path [../README.md](../README.md) returns to the collection. An encoded heading can lead to [a reading section](reading.md#finding-your-place).

## Related images

![Connected documents](../assets/workspace.svg)

Only supported local images are resolved from the opened workspace. Missing resources display an explanation without fetching remote content.
