# Windows file access

Open a local Markdown file or folder. C# owns workspace paths, indexing,
navigation and revisions. The native Win2D graph shows document relationships;
its camera and pointer gestures remain in the Windows process.

The embedded document surface receives parsed snapshots and can request only
validated image reads and document export operations. It has no general shell
or filesystem access. Refresh rereads the folder; map changes use a revision-checked
sidecar. Reading and export do not upload documents. AI actions are explicit.
