# Studio Controls 0.3.0 — preview

A native OBS Studio control desk for Windows 11 and Linux: twelve scenes,
screen zoom and two-axis positioning, independent vignettes, editable project
cards, explicit recording/audio controls and Light/Dark/System appearance.

- **Windows:** extract `StudioControls-windows-x64.zip` into a writable folder
  and run `StudioControls.Windows.exe`. No installation or automatic OBS start.
- **Linux:** install `StudioControls-linux-all.deb` with your distribution's
  package manager so it can resolve the GTK/Python dependencies, then open
  Studio Controls from the applications menu.
- The packages include generic, device-unassigned scene templates. Import a new
  collection and explicitly select devices in OBS. Existing collections are
  never overwritten automatically.
- Connection preferences, project text and rendered custom cards belong to
  per-user storage and are excluded from these downloads. There is no cloud
  telemetry. Public VibeWare/author branding and third-party credits are intentional.
- Windows is unsigned. CI builds the native application and checks synthetic
  rendering, settings and window startup; Linux checks logic, GTK and package
  contents. Interactive OBS and device compatibility still need validation on
  the target Linux and Windows computers. This is a preview, not a claim of
  real-device certification or measured capture performance.

OBS Studio is a separate application. Optional background blur requires the
appropriate obs-backgroundremoval plugin. See the bundled README and notices
for setup, privacy behaviour and asset licences. Verify downloads against
`SHA256SUMS.txt`.
