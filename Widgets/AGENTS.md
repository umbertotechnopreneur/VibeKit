# Widget packaging

- Build distributions from the current widget source.
- For Debian and supported Debian-based Linux distributions, deliver a `.deb` package.
- For public Windows releases, deliver an unsigned `.msi` as the only distribution package. Sign local Windows development builds with the [shared VibeWare development certificate](../docs/windows-development-signing.md) for `CN=Umberto Giacobbi`. Reuse the registered signing key from the Desktop kit.
