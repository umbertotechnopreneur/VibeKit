# Widget packaging

- Build distributions from the current widget source.
- For Debian and supported Debian-based Linux distributions, deliver a `.deb` package.
- For Windows, publish Release builds as a portable ZIP and an unsigned MSI for both x64 and ARM64. Verify the architecture of the binaries and the installer before distribution. Both formats require the external .NET 10 runtime for that architecture. WinUI widgets use .NET Runtime, and Vignette (WPF/Windows Forms) uses Windows Desktop Runtime.
