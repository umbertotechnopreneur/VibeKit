# Studio Controls 0.3.1 — preview

- Native language dropdown: Italian, English, Vietnamese, French, German, Korean,
  Simplified Chinese and Japanese, remembered locally on Linux and Windows.
- Language changes preserve recording/connection state, project text and OBS IDs.
- Linux screen framing rejects a scene change during an in-flight read. Comparison
  validates both screen items before sending its first mutation.
- Server error comments are excluded from Linux errors. Windows cleanup preserves
  the original uncertain request outcome and reports cleanup failures separately.
- Windows diagnostics retain bounded cause types without exception messages.

CI uses synthetic transports and isolated GTK/WinUI sessions. Interactive OBS and
real-device compatibility still need checks on the target computers. Neither
package starts OBS or a recording during installation. See README and notices
for dependencies, credits and setup. Windows is unsigned; this is a preview.
